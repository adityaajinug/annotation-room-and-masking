      Flow: upload a photo, + Add a surface and click the photo to place its dot, pick Include (changes) or Exclude (stays original), draw the shape, upload textures, Test texture / Preview. Everything autosaves in this browser; More → Export JSON for a portable copy.

      Draw: P Pen (click = corner, drag = curve, close on the first point / Enter) · R Rect · O Ellipse · W Wand (click a colour area) · S snap to edges.

      Edit: V Select, then click a shape · drag nodes and handles · double-click an outline = add node · double-click a node = corner/smooth · double-click a rectangle/ellipse = path · Alt+drag a handle = break symmetry.

      Undo: while drawing Ctrl+Z removes the last point, Esc cancels the whole shape. Afterwards Ctrl+Z undoes the shape, Delete removes the selected node or shape.

      View: mouse wheel = zoom at the cursor · hold Space and drag (or middle mouse) = pan · + - zoom · 0 fit.
