        Flow: 1) upload a photo · 2) + Add a surface, then click the photo to place its dot (drag a dot to move it) · 3) Include = area that changes, Exclude = hole that stays the original photo · 4) draw with Pen (click = corner, click + drag = curve, close on the first point), Rectangle or Ellipse · 5) upload textures, then Test texture / Preview · 6) everything autosaves in this browser; More → Export JSON for a portable copy.
        Edit: V Select, then click a shape · drag nodes and curve handles · double-click an outline = add node · double-click a node = corner/smooth · double-click a rectangle/ellipse = turn it into a path · Alt+drag a handle = break symmetry.
        Mistake? Esc cancels the shape you are drawing · Ctrl+Z undo · Delete removes the selected node or shape.
